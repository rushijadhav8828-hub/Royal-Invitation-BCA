# IGNITE 2026 - Royal Freshers Invitation Card 🔥✨

An interactive, animated, luxury digital invitation card created for **Dr. Pranita Chitnis**, Head of Department (HOD), **Department of Commerce & Management**, for **IGNITE - 2026 Freshers Party**.

## 🌟 Highlights & Features
- 👑 **Dedicated VIP Honoree Section:** Features Dr. Pranita Chitnis with glowing orbital halos and dignity insignia.
- 💌 **Interactive Royal Wax Envelope:** Realistic unsealing animation with fanfare and celebration.
- 🔥 **"IGNITE - 2026" Flame Aesthetics:** Fiery gradients, shimmering ember effects, and festive typography.
- 🎆 **Particle & Confetti Systems:** 60fps golden ember canvas and dynamic fireworks confetti cannon.
- 🎵 **Zero-Dependency Synthesizer Audio:** Web Audio API party chord progression and fanfare sounds.
- 🎈 **Floating Emojis Stream:** Continuous stream of celebratory emojis drifting upwards.
- ⏳ **Live Countdown Timer:** Real-time ticker counting down to October 24, 2026.
- 🖨️ **Print & PDF Support:** High-resolution physical invitation card stylesheet for printing or framing.

## 🚀 How to Run
Simply open `index.html` in any modern web browser.
